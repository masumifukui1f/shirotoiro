シロトイロ美容室さま向け

利用規約

第1条（目的）

この規約は、株式会社真寿美衣裳（以下「当社」）が提供する婚礼和装の会員制レンタルサービス「シロトイロ」（以下「本サービス」）の利用条件を定めるものです。

第2条（用語の意味）

1. 「会員」とは、この規約に同意し、年会費を支払い、当社が本サービスの利用を承諾した美容室をいいます。

2. 「非会員」とは、会員以外で、この規約に同意して衣裳を借りる美容室をいいます。本サービスは、会員・非会員とも美容室に限って利用できます。

3. 「衣裳」とは、本サービスで貸し出す白無垢・色打掛などの新婦和装、紋付袴などの新郎和装、および小物をいいます。

4. 「本使用」とは、衣裳をお客様に着用いただき、撮影・挙式・披露宴などに使用することをいいます。

5. 「セット」とは、会員向けの、新婦和装2点・新郎和装1点・小物一式の組み合わせをいいます。

第3条（入会と契約の成立）

1. 入会を希望する美容室は、この規約を確認し、同意したうえで、当社所定の方法で申し込むものとします。

2. 当社が申込みを承諾したのち、美容室は年会費を当社指定の口座へ振り込むものとします。振込手数料は美容室の負担とします。

3. 当社が年会費の入金を確認した時点で、会員契約が成立します。会員料金は、契約成立後のご予約から適用します。

4. 当社は、申込みを承諾しない場合があります。その理由はお伝えしないことがあります。

第4条（年会費）

1. 年会費（税込）は、年会費を振り込んだ日に応じて次のとおりとします。

振込日年会費
2026年12月31日まで12,000円（オープニング特典）
2027年1月1日から2027年12月31日まで24,000円
2028年1月1日から36,000円

2. 入会・更新・再入会のいずれの場合も、振込日の金額を適用します。

3. 年会費は、12か月分を前払いで支払うものとします。振込手数料は美容室の負担とします。

4. 一度支払われた年会費は、理由を問わず返金しません。

第5条（契約期間と更新）

1. 契約期間は、契約成立日から12か月間とします。

2. 当社は、契約期間が終わる60日前までに、会員へ更新のご案内を送ります。

3. 会員が契約期間の終了日までに次の年会費を振り込んだ場合、契約は12か月間更新されます。振込がない場合、契約は期間の終了とともに終わります。

4. 退会または契約の終了ののち再び入会する場合も、第4条のとおり振込日の金額を適用します。

第6条（途中退会）

1. 会員は、契約期間の途中でいつでも退会できます。

2. 途中で退会した場合も、年会費は返金しません。

3. 退会後は、会員料金での新しい予約はできません。

4. 退会の時点ですでに予約している本使用は、会員のときの契約内容（料金・送料・雨天延長保証など）のまま利用できます。

5. 契約期間が終わって更新しなかった場合も、前2項と同じとします。

第7条（料金）

1. 本使用の料金（税込）は次のとおりとします。

会員非会員
料金セット 66,000円新婦和装1点 55,000円／新郎和装1点 33,000円
往復送料当社負担（北海道・沖縄・離島を除く）非会員の負担

2. 会員はセットでのみ利用できます。新婦和装2点は、白無垢・色打掛の組み合わせを自由に選べます。

3. 新郎和装は、黒紋付と白黒の袴とします。

4. 色の追加・変更は、会員・非会員とも次の料金とします。

小物・衣裳内容料金
懐剣・筥迫白から色ものに変更5,500円
掛下白に加えて色ものも届ける11,000円
羽織紐白から色ものに変更2,200円
袴白黒から別の色に変更（差し替え）11,000円

5. 北海道・沖縄・離島へのお届けは、会員の場合も往復の送料を美容室の負担とします。金額は実費とし、予約の際にお知らせします。

6. 本使用の料金（色の追加・変更料金、送料を美容室が負担する場合はその送料を含みます）は、発送日の前の営業日までに、当社指定の口座へ振り込むものとします。振込手数料は美容室の負担とします。

7. 前項の期日までに入金が確認できない場合、当社は発送を見合わせることがあります。

第8条（予約）

1. 予約は、いつでも受け付けます。

2. 同じ衣裳に予約が重なった場合は、先に予約した美容室を優先します。

3. 美容室は、衣裳を7日間仮押さえできます。7日を過ぎると、仮押さえは自動で取り消されます。延長はできません。

4. 予約は、当社所定の予約フォームから行うものとします。予約の際は、次の情報を入力するものとします。

本使用の日

新郎新婦のお名前

新郎新婦の身長・洋服のサイズ・足のサイズ

お届け先

ご注文の衣裳・小物の商品番号

第9条（お届けと返送）

1. 当社は、本使用の日の1週間前までに衣裳が届くよう発送します。

2. 美容室は、本使用の日の翌日に、届いた衣裳・小物（足袋・肌着・草履を含む）をすべて当社へ返送するものとします。

3. 本使用の日から7日を過ぎても返送されない場合、8日目から1日につき、その本使用のご請求金額の10%を延滞料として支払うものとします。

4. 第10条の延長をした場合も、前項の期限は変わりません。

第10条（雨天延長保証）

1. 本使用の日が天候不良（雨・台風・大雪・自然災害、その他の不可抗力を含みます）の場合、美容室は最大3日まで延長して衣裳を使用できます。追加料金はかかりません。

2. 延長する場合は、本使用の日のうちに、LINEで当社へ連絡するものとします。

第11条（キャンセル）

1. 発送前のキャンセルは無料とします。

2. 発送後のキャンセルは、会員はセット料金の50%、非会員はご利用料金の50%をキャンセル料として支払うものとします。

3. 発送後にキャンセルした場合も、衣裳は速やかに返送するものとします。

第12条（禁止事項）

1. 美容室は、次のことをしてはいけません。

1. 衣裳を、ほかの美容室・写真スタジオ・事業者などへ貸したり（又貸し）、譲ったりすること

2. 会員料金で予約した衣裳を、ほかの美容室・事業者のお客様のために使うこと

3. 会員の資格や会員料金を、ほかの美容室・事業者に使わせること

4. 衣裳を加工・改造すること

5. 予約した本使用以外の目的で衣裳を使うこと

2. 美容室が前項に違反した場合、当社は契約を解除し、その美容室による本サービスの利用を永久に停止します。この場合、年会費は返金しません。

3. 前項の場合、違反にかかわる本使用の料金は非会員の料金で計算し直し、すでにお支払いいただいた料金との差額を、美容室に請求します。

第13条（汚れ・損傷のご報告）

1. 衣裳が届いたときに、汚れ・ほつれ・損傷など気になる点があれば、当社へご連絡ください。

2. ご使用中に汚れや損傷が生じた場合や、衣裳・小物が見当たらなくなった場合は、返送の際にあわせて当社へご報告ください。

3. ご報告いただいた内容への対応は、当社とご相談のうえ決めるものとします。

第14条（契約の解除）

美容室がこの規約に違反した場合、当社は事前の連絡なしに契約を解除できます。この場合、年会費は返金しません。

第15条（当社の責任）

1. 当社の都合で衣裳が本使用の日までに届かなかった場合、当社はその本使用の料金を全額返金します。あわせて、代わりの衣裳を無料でご用意します。

2. 天災・運送事故など当社の責任によらない理由で衣裳の到着が遅れた場合、当社はその責任を負わないものとします。

第16条（個人情報）

当社は、美容室および美容室のお客様の情報を、本サービスの提供のためにのみ使い、当社のプライバシーポリシーに従って適切に取り扱います。

第17条（規約の変更）

当社は、必要に応じてこの規約を変更できます。変更する場合は、WEBサイトまたはLINEで事前にお知らせします。

第18条（裁判所）

本サービスに関する争いは、福井地方裁判所を第一審の専属的合意管轄裁判所とします。

附則：この規約は2026年10月24日から適用します。
